# AyurChain Backend — Botanical Blockchain Node & API Server

Express Node.js backend server supporting the AyurChain botanical supply chain verification protocol.

## Features
- **Smart Contract Intermediary**: Interacts with Sepolia testnet nodes.
- **IPFS Pinning Service**: Gateway for storing lab quality certificates and collection permits.
- **Fraud Anomaly Engine**: Performs time-vs-distance validation on GPS logs between supply chain stages.

## Quick Start
```bash
npm install
npm run dev
```

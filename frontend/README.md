# AyurChain Frontend — Botanical Supply Chain Web App

React 18 + Vite + Tailwind CSS frontend application for **AyurChain** (SIH Prototype Submission).

## Features
- **Hero & Landing Page**: Animated particle layout with stat counters & process timeline.
- **Role-Based Dashboard**: Views tailored for Farmers, NABL Quality Labs, Manufacturers, Consumers & Regulators.
- **Public Traceability (`/trace/:batchId`)**: Immutable 6-stage chain-of-custody timeline with GPS maps and IPFS documents.
- **Farmer Registration & Batch Logger**: 5-step wizard and mobile scanner with offline local cache sync.
- **Regulator Portal**: Recharts analytics, fraud alert anomaly detection, and compliance report exporter.

## Quick Start
```bash
npm install
npm run dev
```

# AyurChain — Blockchain Botanical Traceability System

AyurChain is an immutable blockchain-based supply chain tracking platform for Ayurvedic herbs from forest harvesting to final product formulation.

## Repository Structure
- [`frontend/`](file:///Users/krishu/Desktop/sihp1/frontend) — React 18 + Vite + Tailwind CSS + Ethers.js UI application.
- [`backend/`](file:///Users/krishu/Desktop/sihp1/backend) — Express API server node & Smart Contract integration layer.

## Setup & Running

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```
